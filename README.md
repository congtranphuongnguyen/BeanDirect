# BeanDirect - Website Bán Cà Phê Trực Tiếp Cho Thương Hiệu Nhỏ An Toàn Theo Chuẩn OWASP ASVS

## 1. Tên đề tài
* **Tiếng Việt:** Phát triển BeanDirect: website bán cà phê trực tiếp cho thương hiệu nhỏ an toàn theo chuẩn kiểm chứng OWASP ASVS
* **Tiếng Anh:** Developing BeanDirect: A Secure Direct-to-Consumer Coffee Store for Small Brands Based on the OWASP ASVS

## 2. Câu định vị
> "Đồ án giải quyết vấn đề mất an toàn thông tin giao dịch cho các thương hiệu cà phê nhỏ (D2C) dựa trên tiêu chuẩn kiểm chứng OWASP ASVS Mức 1, đo bằng số lượng lỗ hổng tự động giảm bớt và tỉ lệ tuân thủ tiêu chuẩn an ninh."
